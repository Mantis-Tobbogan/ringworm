# Code of conduct

Ringworm is a small project about making screens easier to use. Everyone is
welcome to use it, report bugs, and contribute — regardless of experience,
identity, or ability.

## Expected behaviour

- Be respectful and assume good faith. Critique code, not people.
- Accessibility reports are first-class: if the ring does not work for you,
  that is a bug worth fixing, not a user error.
- Keep discussions on topic; move unrelated debates elsewhere.
- Respect privacy. Do not ask people to post screenshots of their desktop,
  session logs, or anything else that might expose personal data. Ask for the
  output of `ringworm status` or `niri msg version` instead.

## Not acceptable

Harassment, insults, discriminatory language, sexualised attention, doxxing,
and publishing others' private information without consent. Sustained
disruption of issues or pull requests is also not acceptable.

## Scope

This applies to issues, pull requests, discussions, and any project space,
and to behaviour in public when representing the project.

## Enforcement

Report problems to the maintainer privately — via the GitHub profile
[@Mantis-Tobbogan](https://github.com/Mantis-Tobbogan) or the repository's
**Security → Report a vulnerability** form if you prefer a private channel.
Reports are handled confidentially. The maintainer may edit or delete
comments, close threads, or block accounts, and will explain the reason when
it is safe to do so.
